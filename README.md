## 5. Формулы

- Масса партии листов:

  **m = L · W · (t / 1000) · ρ · q**, кг

где:
- `L` — длина листа, м;
- `W` — ширина листа, м;
- `t` — толщина листа, мм (делим на 1000 для перевода в метры);
- `ρ` — плотность материала, кг/м³;
- `q` — количество листов, шт.

## 7. Допустимые диапазоны входных данных

| Параметр          | Обозначение | Диапазон       |
|-------------------|-------------|----------------|
| Длина листа       | L, м        | **0.1 .. 5**   |
| Ширина листа      | W, м        | **0.1 .. 3**   |
| Толщина листа     | t, мм       | **0.1 .. 20**  |
| Количество листов | q, шт.      | **1 .. 1000**  |

Ввод вне диапазона или нечисловое значение → сообщение об ошибке, запись в `input_errors.log`, повторный запрос.

---

## 8. Правила классификации толщины

| Условие          | Класс толщины       |
|------------------|---------------------|
| `t < 0.5`        | тонкий лист         |
| `0.5 ≤ t ≤ 5`    | нормальная толщина  |
| `t > 5`          | толстый лист        |
